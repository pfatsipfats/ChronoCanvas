# ChronoCanvas

Port of rendering engine from [ChronoZoom](https://github.com/alterm4nn/ChronoZoom).

## Features

HTML5 Canvas rendering engine with smooth navigation and elliptical zoom feature.

# Contributing

## Prerequisites
- Node.js 24.x
- pnpm 10.x

## Building
```bash
pnpm install
pnpm build
```

## Running the sample app
```bash
cd sample
pnpm install
pnpm dev
```
